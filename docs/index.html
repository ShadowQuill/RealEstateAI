REAL ESTATE · AI · 54 CITIES · v1.1.0

RealEstateAI

房地产 AI 分析系统：二手房价格预测、城市房价趋势研判、 多城横向对比与 AI 房源文本分析。覆盖数据采集 → 价格预测 → 趋势预测 → 宏观研判 → 智能问答全链路， 支持 54 个城市（链家/贝壳二手房数据 + 国家统计局 70 城房价指数），并可通过 Docker 一键部署。

核心能力

🏙️

54 城数据

链家/贝壳二手房成交 + 国家统计局 70 城房价指数，覆盖全国主要城市。

💰

价格预测模型

XGBoost + 随机森林融合，对房源总价/单价进行回归预测。

📈

城市房价趋势

基于官方同比/环比指数，研判城市房价未来走势。

🆚

城市对比

多城房价横向对比，可一键过滤样本量过少的城市，结论更可信。

🌐

宏观环境

CPI / GDP / M2 / PMI / 利率等宏观指标，附新手说明，看得懂。

💬

AI 文本分析

对房源描述做 NLP 解析，提炼户型、楼层、配套等结构化信息。

🤖

LLM 智能问答

可接入 OpenAI / DeepSeek，RAG 检索强制引用数据来源、抑制幻觉。

🐳

容器化部署

提供 Docker / docker compose 一键启动，含 Railway、Render 云端部署指南。

技术栈

Python XGBoost Random Forest 时间序列预测 NLP RAG / TF-IDF OpenAI / DeepSeek Playwright FastAPI React Vite Recharts Tailwind CSS Radix UI Docker Dash SQLite

部署方式

本地一键
python run_system.py --with-frontend（API 默认 8000，前端 5173，看板 8050）
Docker
docker compose up -d --build，详见 DEPLOY.md
云部署
支持 Railway、Render（见 DEPLOY.md 指南）
