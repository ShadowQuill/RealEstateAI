REAL ESTATE · AI · 54 CITIES

RealEstateAI

房地产 AI 分析系统：二手房价格预测、城市房价趋势研判与 AI 房源文本分析。覆盖数据采集 → 价格预测 → 趋势预测 → 智能分析全链路， 支持 54 个城市（链家/贝壳二手房数据 + 国家统计局 70 城房价指数）。

核心能力

🏙️

54 城数据

链家/贝壳二手房成交 + 国家统计局 70 城房价指数，覆盖全国主要城市。

🤖

价格预测模型

XGBoost + 随机森林融合，对房源总价/单价进行回归预测。

📈

趋势预测

基于官方同比/环比指数，研判城市房价未来走势。

💬

AI 文本分析

对房源描述做 NLP 解析，提炼户型、楼层、配套等结构化信息。

技术栈

Python XGBoost Random Forest 时间序列预测 NLP Playwright FastAPI React Vite Dash SQLite
